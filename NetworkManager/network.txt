however : When DNS comes from DHCP via NetworkManager:

So this file acts mainly as:
fallback DNS
manual configuration if no network manager exists


Priority order (important)
In Ubuntu desktop the priority is typically:
1️⃣ resolvectl manual settings (temporary)
2️⃣ NetworkManager connection DNS
3️⃣ DHCP DNS (from router)
4️⃣ /etc/systemd/resolved.conf fallback

So NetworkManager usually wins.

so the right methode : 
How to change DNS permanently (correct way for you)
Since NetworkManager manages your network, the correct place is NetworkManager.
First find your connection name:
			>	nmcli connection show
Then set DNS:
			>	sudo nmcli connection modify "HELIX205" ipv4.dns "8.8.8.8 1.1.1.1"
				sudo nmcli connection modify "HELIX205" ipv4.ignore-auto-dns yes
				
Then reconnect:	        >	nmcli connection down "HELIX205"
				nmcli connection up "HELIX205"			

Now check:              >	resolvectl status
			> cat ls /run/systemd/resolve/resolv.conf  : it will have the new values because it been generated dynamically by systemd-resolved and disappear after reboot.
